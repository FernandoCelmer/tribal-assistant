# Bosque

Fonte: https://help.tribalwars.com.br/index.php?title=Bosque

Os lenhadores cortam madeira dos bosques que rodeiam as aldeias. Tal madeira é necessária para o desenvolvimento da própria aldeia, assim como para o fortalecimento do exército. Quanto mais alto o nível dos lenhadores, mais madeira será produzida.

Nível maximo: **30**

**Requerimentos:** O Bosque não é uma construção dependente de outros edifícios.
