# Medalhas

Fonte: https://help.tribalwars.com.br/index.php?title=Medalhas

### Molduras

Algumas medalhas possuem diferentes níveis que são identificados por moldura em madeira, bronze, prata e ouro. Sendo a madeira a medalha de menor nível e a de ouro a medalha de maior nível, onde cada nível de medalha que você possui equivale a 1 ponto na classificação das realizações. Consulte a tabela abaixo para conhecer os diferentes tipos de molduras:
