# Aldeias

Fonte: https://help.tribalwars.com.br/index.php?title=Aldeias

Tribal Wars gira principalmente em torno das **aldeias**, nelas você consegue criar e evoluir os [Edifícios](edificios.md), criar [Unidades](unidades.md), entre muitas outras finalidades.

![](https://help.tribalwars.com.br/images/thumb/c/c5/Capturaraldeia.JPG/300px-Capturaraldeia.JPG)exemplo de aldeia

### Tipos de Aldeias

Existem os seguintes tipos de **aldeias**:

- [Aldeia de Bárbaros](aldeia-de-barbaros.md)
- [Aldeias Bônus](aldeias-bonus.md)

### Especializações

Uma boa prática para evolução de suas **aldeias** é você criar cada uma com uma finalidade, segue abaixo as principais especializações:

##### unidades

As unidades são a defesa e o ataque da aldeia, podem ser criadas no: [quartel](https://help.tribalwars.com.br/index.php?title=Quartel), no [estábulo](estabulo.md), na [oficina](oficina.md), na [academia](academia.md) e na [estátua](estatua.md), são elas:

1. [quartel](https://help.tribalwars.com.br/index.php?title=Quartel): [lanceiro](lanceiro.md), [espadachim](espadachim.md), [bárbaro](barbaro.md), [arqueiro](arqueiro.md).
2. [estábulo](estabulo.md): [explorador](explorador.md), [Cavalaria Leve](cavalaria-leve.md), [arqueiro a cavalo](arqueiro-a-cavalo.md), [Cavalaria Pesada](cavalaria-pesada.md).
3. [oficina](oficina.md): [aríetes](ariete.md), [catapulta](catapulta.md).
4. [estátua](estatua.md): [paladino](paladino.md)
5. [academia](academia.md): [nobre](nobres.md)
