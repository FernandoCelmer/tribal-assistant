# Fundador inactivo

Fonte: https://help.tribalwars.com.br/index.php?title=Fundador_inactivo

Muitos utilizadores têm perguntado pelo o fórum do tribal wars o que acontece quando o fundador de uma tribo fica inativo, veja a imagem:

![](https://help.tribalwars.com.br/images/thumb/a/a3/Liderinativo.png/600px-Liderinativo.png)Fundador inativo.

Quando a conta do fundador da tribo se apaga automaticamente todos podem ver no visualização geral o pedido para se tornar fundador da tribo onde o primeiro a clicar se torna fundador.

Se existir um administrador da tribo aparece para os administradores e é o mesmo, o primeiro a clicar é o novo fundador da tribo.
