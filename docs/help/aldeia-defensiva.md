# Aldeia Defensiva

Fonte: https://help.tribalwars.com.br/index.php?title=Aldeia_Defensiva

#### As ALDEIAS DEFENSIVAS devem englobar somente as seguintes tropas:

- [Lanceiros](lanceiro.md)

- [Espadachim](espadachim.md)

- [Arqueiros](arqueiro.md)

- [Cavalaria Pesada](cavalaria-pesada.md)

- [Espiões](explorador.md)

#### Uma das boas opções de defesa é :

- 4000 [Lanceiros](lanceiro.md)
- 4000 [Espadachim](espadachim.md)
- 4500 [Arqueiros](arqueiro.md)
- 1250 [Cavalaria Pesada](cavalaria-pesada.md)

#### Os edificios recomendam se assim:

- [Edifício Principal](edificio-principal.md) (Nível 20)

- [Quartel](https://help.tribalwars.com.br/index.php?title=Quartel) (Nível 25)

- [Estábulo](estabulo.md) (Nível 10-20)

- [Oficina](oficina.md) (Nível 0)

- [Academia](academia.md) (Nível máximo, independentemente do mundo)

- [Ferreiro](ferreiro.md) (Nível 20)

- [Praça de Reunião](https://help.tribalwars.com.br/index.php?title=Pra%C3%A7a_de_Reuni%C3%A3o) (Nível 1)

- [Mercado](mercado.md) (Nível 15-20)

- [Bosque](bosque.md) (Nível 30)

- [Poço de Argila](https://help.tribalwars.com.br/index.php?title=Po%C3%A7o_de_Argila) (Nível 30)

- [Mina de Ferro](mina-de-ferro.md) (Nível 30)

- [Fazenda](fazenda.md) (Nível 30)

- [Armazém](armazem.md) (Nível 30)

- [Esconderijo](esconderijo.md) (Nível 0) Este edifício apenas ocupa espaço na fazenda das [aldeias](aldeias.md) completas

- [Muralha](muralha.md) (Nível 20)
