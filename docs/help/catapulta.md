Utilizada para reduzir o nível de qualquer edifício menos o [Esconderijo](esconderijo.md) da aldeia inimiga e tal como o aríete a sua eficácia está relacionada com as tropas que a acompanham. Devido à "absurda" população que ocupam não aconselho utilizarem-nas na defesa, tanto o [espadachim](espadachim.md).

As catapultas atacam "sempre" depois do ataque ao contrário dos [aríetes](ariete.md), sendo assim tornam-se pouco práticas para destruir a muralha uma vez que não aumenta o "bónus" de ataque...

**Eis alguns alvos para as catapultas:**

- [Praça de Reunião](https://help.tribalwars.com.br/index.php?title=Pra%C3%A7a_de_Reuni%C3%A3o) - Quando destruída impossibilita o jogador de mover tropas nessa aldeia. Contudo é um edifício rápido de construir, mesmo assim é útil para quando queremos que o inimigo não desvie tropas.

- [Fazenda](fazenda.md) - "Tira" a possibilidade de o inimigo criar mais tropas dependendo dos níveis que são destruídos.

- [Ferreiro](ferreiro.md) - Impede o inimigo de criar nobres e armazenar recursos/moedas de ouro. Dependendo do nível que o Ferreiro é destruído impossibilita o defensor criar alguns tipos de tropas (ex. Cp´s);

- [Bosque](bosque.md), [Argila](https://help.tribalwars.com.br/index.php?title=Argila) e [Ferro](https://help.tribalwars.com.br/index.php?title=Ferro) - Diminui a produção de recursos;

- [Quartel](https://help.tribalwars.com.br/index.php?title=Quartel), [Estábulo](estabulo.md), [Oficina](oficina.md) - Impede o inimigo de criar tropas já que os Edifícios produtores são destruídos.
