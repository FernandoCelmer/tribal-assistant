# Academia

Fonte: https://help.tribalwars.com.br/index.php?title=Academia

A Academia é o edifício onde são treinados os [Nobres](nobres.md), este edifício é fundamental para a conquista de novas [Aldeias](aldeias.md). O sistema de criação de [Nobres](nobres.md) funciona da seguinte forma, para a formação do primeiro, utiliza-se uma moeda de ouro (ou pacote de recursos, dependendo do mundo), a partir deste, aumenta-se o preço dos próximos.

Dependendo do mundo, o nível máximo da academia pode ser 1 ou 3.  
**Requerimentos:** [Mercado](mercado.md) nível 10, [Edifício Principal](edificio-principal.md) nível 20 e [Ferreiro](ferreiro.md) nível 20
