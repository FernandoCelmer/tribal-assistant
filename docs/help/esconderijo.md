# Esconderijo

Fonte: https://help.tribalwars.com.br/index.php?title=Esconderijo

É o mais barato é o mais rápido de se fazer. O esconderijo em caso de ataque guardar parte de seus recursos em sua aldeia. Quanto mais evoluído mais recursos o esconderijo guarda.

Nível maximo: **10**

**Requerimentos:** O Esconderijo não é dependente de outras construções.
