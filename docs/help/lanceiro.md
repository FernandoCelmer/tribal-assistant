O lanceiro é a unidade mais simples do [Tribal Wars](https://help.tribalwars.com.br/index.php?title=Tribal_Wars) e não prescisa de pesquisa, apenas é necessário o quartel a nível 1. Esta unidade é defensiva, mas apesar de tudo é uma unidade rápida.E importante saber que o lanceiro para defesa é necessário uma outra tropa junto a ela para sua força ficar maior.

Para mais informações consulte: [Esta página](http://br23.tribalwars.com.br/help2.php?article=units)
