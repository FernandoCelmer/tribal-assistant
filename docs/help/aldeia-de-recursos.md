# Aldeia de Recursos

Fonte: https://help.tribalwars.com.br/index.php?title=Aldeia_de_Recursos

As aldeias de recursos podem ser utilizadas para enviar recursos destinados a ajudar na evolução das aldeias que ainda estão em construção, seja essa construção de edifícios, ou mesmo o recrutamento de tropas. As [Aldeias Bônus](aldeias-bonus.md) se tornam mais eficientes para esse tipo de especialização de aldeia, pois a sua produção de recursos é mais rápida.
