# Estátua

Fonte: https://help.tribalwars.com.br/index.php?title=Est%C3%A1tua

Na estátua é onde se nomeia o [paladino](paladino.md),se o seu [paladino](paladino.md) morrer em uma batalha você deverá nomear um novo [paladino](paladino.md).

Nível maximo: **1**

**Requerimentos:** Não dependente da construção de outros edifícios.
