# Estábulo

Fonte: https://help.tribalwars.com.br/index.php?title=Est%C3%A1bulo

No estábulo são treinados quatro tipos de tropas envolvendo cavaleiros, tanto para ataque quanto para defesa.No estábulo então é possível treinar [Exploradores](explorador.md), [Cavalaria Leve](cavalaria-leve.md), [Arqueiro a cavalo](arqueiro-a-cavalo.md) e [Cavalaria Pesada](cavalaria-pesada.md). Quanto maior nível do estábulo mais rápido será o treinamentos das cavalarias.

Nível máximo: **20**

**Requerimentos:** [Quartel](https://help.tribalwars.com.br/index.php?title=Quartel) (Nível 5) [Ferreiro](ferreiro.md) (Nível 5) [Edifício Principal](edificio-principal.md) (Nível 10)
