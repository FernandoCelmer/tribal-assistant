# Aldeia de Espiões

Fonte: https://help.tribalwars.com.br/index.php?title=Aldeia_de_Espi%C3%B5es

Aldeias de espiões: nessas [aldeias](aldeias.md) são produzidas apenas [exploradores](explorador.md), que servem basicamente para explorar as aldeias de outros jogadores. Podem ser muito utilizadas na frente de guerra, onde podem ser usados como apoios para o inimigo não descobrir as tropas presentes em suas aldeias ou mesmo em aldeias aliadas, como atacantes, espionando os níveis dos edifícios, as tropas e os recursos presentes nas aldeias adversárias, além de ser ideais para a criação de ataque fakes.

Uma boa sugestão para uma aldeia de exploradores é:

5.000 lanceiros;

5.000 espadachins;

5.500 exploradores
