**- Texto descritivo:**

**O Espadachim é uma unidade de defesa, sendo a melhor unidade contra os ataques "gerais" **.**

O Espadachim é uma unidade diferente do [lanceiro](lanceiro.md), ou seja o [lanceiro](lanceiro.md) é possível recrutar quando se tem o [quartel](https://help.tribalwars.com.br/index.php?title=Quartel), e o espadachim, é necessário ter o [ferreiro](ferreiro.md) construí do, mas não é necessário pesquisá-lá, como as restantes unidades.

Esta unidade gasta muito [ferro](https://help.tribalwars.com.br/index.php?title=Ferro) e é ótima para "contrabalançar" os recursos, contudo não é boa para [farmar](https://help.tribalwars.com.br/index.php?title=Farmar) ao invés do lanceiro.

O forte dos espadachins é a sua defesa contra [Arqueiros](arqueiro.md) e [Bárbaros](barbaro.md)...no entanto é extremamente vulnerável contra ataques de Cavalarias Leves. O seu ponto fraco é a sua baixa Defesa contra Cavalaria o que faz do Espadachim uma "presa fácil" tanto para a [Cavalaria Leve](cavalaria-leve.md) como para a [Cavalaria Pesada](cavalaria-pesada.md)
