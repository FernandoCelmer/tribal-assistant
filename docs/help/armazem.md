# Armazém

Fonte: https://help.tribalwars.com.br/index.php?title=Armaz%C3%A9m

No Armazém são guardados os [recursos](https://help.tribalwars.com.br/index.php?title=Recursos) produzidos pela [aldeia](https://help.tribalwars.com.br/index.php?title=Aldeia). Quanto maior for o nível do Armazém, maior será a sua capacidade de armazenamento.

Nível maximo: **30**

**Requerimentos:** O Armazém não é dependente de outras construções.
