# Como saber o continente de uma aldeia olhando pelas coordenadas!

**Origem:** https://forum.tribalwars.com.br/index.php?threads/como-saber-o-continente-de-uma-aldeia-olhando-pelas-coordenadas.12097/

---

Eu prestei atenção numa coisa muito importante, dá para descobrir o continente dos outros jogadores pelas cordenadas!  
  
Vou dar um exemplo, 542|324, simples, é só pegar o primeiro número do eixo y que é 3 e juntar com o primeiro número do eixo x que é 5, juntando os dois vira 35, então quer dizer que esta aldeia qualquer está no continente 35  
  
(primeiro número x)>542|3>( primeiro número y)24  
  
Tentem fazer com suas próprias coordenadas que dá certo!
