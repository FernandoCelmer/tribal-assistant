# [Tutorial] Aprenda a ativar seu Javascript

**Origem:** https://forum.tribalwars.com.br/index.php?threads/tutorial-aprenda-a-ativar-seu-javascript.45315/

---

Pra quem não sabe _javascript_ é uma linguagem de programação criada pela Netscape em 1995, que a princípio se chamava LiveScript, afim de atender as seguintes necessidades:  
  


  * Validação de formulários no lado cliente (programa navegador);
  * Interação com a página.

Ele é necessário para que você execute seus scripts.  
  
Se em seu navegador estiver desativado, pouco se aproveitará da CP (Conta Premium), já que é um dos principais benefícios desta 'conta VIP'.  
  
Abaixo um pequeno Tutorial que os ensinarão a ativá-lo:  
  
  


  * **Internet Explorer 8 ou inferior**

  
  


  1. Clique no menu **Ferramentas** ;
  2. Selecione **Opções de Internet** ;
  3. Clique na guia **Segurança** ;
  4. Clique no botão **Nível Personalizado** ;
  5. Role para baixo até ver a seção "Scripts". Selecione o botão de opção "Ativar" para "Scripts ativos";
  6. Clique no botão **OK** ;
  7. Clique no botão **Sim** na janela de confirmação.

  
  
  


  * **Google Chrome**

  


  1. Clique no ícone de menu na barra de ferramentas do navegador 

![dgo5.png](http://img801.imageshack.us/img801/8004/dgo5.png)

;
  2. Selecione **Configurações** ;
  3. Clique em **Mostrar Configurações avançadas** ;
  4. Em **Privacidade** , clique em **Configurações de conteúdo** ;
  5. Em **Javascript** , ative a opção **Permitir que todos os sites executem JavaScript (recomendado)**.

  
  
  


  * **Mozilla Firefox**

  
  
  


  1. Clique no menu **Ferramentas** ;
  2. Selecione **Opções** ;
  3. Clique na guia **Conteúdo** ;
  4. Marque a caixa de seleção **Ativar JavaScript** ;
  5. Clique no botão **OK**.

  
  
  


  * **Safari**

  
  
  


  1. Clique no menu **Safari** ;
  2. Selecione **Preferências** ;
  3. Clique na guia **Segurança** ;
  4. Marque a caixa de seleção "Ativar JavaScript".

  
  
  


  * **Opera**

  
  
  


  1. Clique no menu **Ferramentas** ;
  2. Selecione **Preferências** ;
  3. Clique na guia **Avançado** ;
  4. Clique em **Conteúdo** ;
  5. Marque a caixa de seleção "Habilitar JavaScript";
  6. Clique no botão **OK**.

  
  
  


  * **Netscape**

  
  
  


  1. Clique em **Editar** ;
  2. Agora procure a guia **Preferências** ;
  3. Selecione **Avançado** ;
  4. Em _Scripts and Windows_ selecionar "Habilitar Javascript".
