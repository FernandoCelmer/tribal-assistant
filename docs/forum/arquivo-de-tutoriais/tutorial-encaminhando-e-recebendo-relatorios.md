_»_ **PASSO 01** _**Encaminhando relatórios** _  
  
Selecionar os relatórios que deseja **Encaminhar** para _amigo,esposa,maridos,cachoro,papagaio etc._   
Após selecionar os relatórios que deseja **Encaminhar** , clique em **"Encaminhar"**  
  
  


![f44w.png](http://img138.imageshack.us/img138/4695/f44w.png)

  
  
  
_»_ **PASSO 02****Encaminhando relatórios**   
  
Digite o nome do **player** que voce deseja enviar os relatorios (Neste caso enviei para mim mesmo para desmotrar como receber os relatorios)  
clique em **Encaminhar** e pronto!.  
  


![RoJ87sN.png](http://i.imgur.com/RoJ87sN.png)

  
  
  
_»_ _**Recebendo os Relatorios Encaminhados.**_  
  
Irar Aparecer um Relatorio perguntando se voce deseje aceitar os relatorios Encaminhados  
Clique para abrir o relatorio.  


![dkoSnPW.png](http://i.imgur.com/dkoSnPW.png)

  
  
  
Clique em Aceitar Oferta para receber os relatorios.  
  


![wto1.png](http://img710.imageshack.us/img710/1051/wto1.png)

  
  
  
Pronto Voce receberar todos os relatorios encaminhados,eles terar uma seta de encaminhamento ao lado.  
  


![ZHiFt76.png](http://i.imgur.com/ZHiFt76.png)

  
  
  
O encaminhamento de relatorios pode ser ultilizado de varias formas, trasferir informaçoes de tal aldeia, ou até mesmo como ajuda a outros players, Como mostro em outro tutorial que estou terminando,
