Bem como a maioria já sabe , vou ensinar como identificar um ataque para os novos jogadores.  
  
Requisitos :  
  
\- Conta Premiun  
\- Online ( No horário do ataque )  
  


![jxrvrbY.png](http://i.imgur.com/jxrvrbY.png)

  
  
Visualize os comandos a sua aldeia ..  
  


![s2ZsjjS.png](http://i.imgur.com/s2ZsjjS.png)

  
  
Abra o "Ataque" para saber mais.  
  


![mxrm.png](http://img199.imageshack.us/img199/7541/mxrm.png)

  
  
Cliquem em "mostrar duração (Ferramenta de abas)" para saber o tempo das unidades.  
  


![FqdD8kb.png](http://i.imgur.com/FqdD8kb.png)

  
  
Compare os horários de cada unidade e o horário das tropas e renomeie o ataque ![;\)](https://cdn.jsdelivr.net/joypixels/assets/8.0/png/unicode/64/1f609.png)
