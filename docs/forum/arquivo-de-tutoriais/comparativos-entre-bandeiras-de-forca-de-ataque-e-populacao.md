**CONCLUSÃO**  
  
As bandeiras de **População 3% (MARROM)** superam as expectativas das bandeiras de **Ataque 5% (AMARELA).  
  
Jogadores Defensivos do mar azul:**  
  
A bandeira de população ainda é a melhor escolha para você, pois é de extrema importância fazer mais tropas para enviar a fronteira.  
  
**Ataques que partem do mar azul:**  
  
Utilize as **bandeiras de velocidade de recrutamento*** até atingir a população máxima e depois mude para **bônus de população.  
  
Ataques que partem do Front (1 a 10 campos):**  
  
Se você é jogador de fronteira você precisa de tropas rápidas, certo? Então durante o recrutamento você irá usar as **bandeiras de velocidade de recrutamento** e só depois você irá mudar para a **bônus de população.  
  
* Priorize as aldeias do front em detrimento do mar**
