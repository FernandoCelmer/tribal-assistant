Boas pessoal, aqui vou-vos ensinar como coordenar ataques de uma só aldeia:  
  
Primeiro têm de ter o browser Opera, este é o melhor para coordenar ataques.  
  
Depois têm de configurar o browser deste modo (Peço desculpa por o meu browser estar em ingles e não em português, mas o método é igual):  
  


![Tutorialforquicknoblepic1.jpg](http://i189.photobucket.com/albums/z17/daisho_2007/Tutorialforquicknoblepic1.jpg)

  
  
Agora estamos prontos para enviar o "train" (comboio de nobres).  
O método é simples, abres 4 separadores com o mesmo destino e introduzes as unidades que queres enviar, no caso de ser um train, envias sempre mais força atacante no 1º ataque juntamente com os nobres e nos restantes basta enviar 50 CL com o nobre.
