# Fast storage ]tutorial[ armazenar rapido sem cp

**Origem:** https://forum.tribalwars.com.br/index.php?threads/fast-storage-tutorial-armazenar-rapido-sem-cp.155917/

---

Pessoal eu criei esse tuto com fundamentos do tutorial do pauloguimor o de Fast Farm que é pra farmar rapido esse tutorial do **FAST STORAGE** é pra armazenar recursos para nobres com um pouco mais de facilidade basta ter em seu computador o navegador [OPERA ](http://hotfile.com/dl/117094986/0815e08/Opera_1110_int_Setup.exe.html)e configurar ele do mesmo jeito do FAST FARM Após instalado, abra-o.  
  
Em seguida aperte Crtl + F12 (vai abrir essa tela):
