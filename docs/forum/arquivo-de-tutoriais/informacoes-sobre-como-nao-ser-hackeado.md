_Hackear ao contrário do que muitos pensam não é nem nunca será roubar senhas! Quem tem a senha roubada é muito estupido! __Ora bem!__  
__Uma das maneiras mais simples é hackear pelo msn ou ganhando seu ip através do msn!__  
  
_**E como se rouba o IP de uma outra pessoa?**_  
_Muito bem, só pessoas avançadas o sabem fazer! Mas uma das maneira pas o prevenir é nunca acessar links dados por jogadores não confiáveis! Não partilhar imagens com pessoas não confiaveis ou qualquer coisa do género!_  
  
_O hacker uma vez partilhando consigo imagens, sites ou até mesmo jogando consigo, através de um programa que todos os pc's com windows ******** têm desde que são feitos fica com seu IP!_  
  
_**Por isso já sabem, nunca joguem, partilhem ou acessem links de pessoas não confiaveis!!**_
