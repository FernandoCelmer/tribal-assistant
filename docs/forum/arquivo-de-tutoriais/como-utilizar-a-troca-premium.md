# Como utilizar a Troca Premium

**Origem:** https://forum.tribalwars.com.br/index.php?threads/como-utilizar-a-troca-premium.334558/

---

Tutorial simples que fiz para minha tribo no BR84, base em início do mundo.  
  
Agora é possível vender e comprar recursos utilizando os pontos premium, no _mercado_ , em **Troca Premium**.  
  
**Compra de recursos:**  
Não são gastos nenhum mercador, e demora 1hora e 15min para ser entregue na aldeia.  
  
**Venda de recursos:**  
São gastos mercadores, quanto mais recursos + mercadores necessários para fazer a troca.  
  
-  
  
Por exemplo, tenho 1000 de madeira, 5000 de argila e 2000 de ferro.  
Vou vender 2000 de argila e com esses PPs que vou adquirir, vou gastar comprando +ferro e +madeira.  
  
O segredo é esse, balancear os recursos na aldeia.  
  
**Agora vamos lá, quando é a hora certa de negociar os recursos?**  
Quando os preços estão baixos.  
Por exemplo, 70 recursos = 1PP.  
Essa é a hora de VENDER!  
  
Quando os preços estão altos.  
Exemplo, 300 recursos = 1PP.  
É a hora de COMPRAR.  
  
Em diferentes horários do dia mudam a **oferta x procura** e alteram assim os preços, por isso é importante acompanhar e saber a hora certa de negociar.  
  
Quando o estoque está **alto** >> recursos caros para venda, barato para compra.  
Quando o estoque está **baixo** >> recursos baratos para venda, caro para compra.
