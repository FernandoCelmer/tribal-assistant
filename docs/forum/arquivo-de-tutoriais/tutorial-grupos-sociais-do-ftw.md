  * **Criando um Grupo Social**

Link: <http://forum.tribalwars.com.br/group.php?do=create>  
  
Vai aparecer a seguinte imagem:  


![37506580.png](http://img829.imageshack.us/img829/2228/37506580.png)

  


◆ É a categoria do grupo. Escolha a segunda opção.  
◆ Nome do grupo.  
◆ Descrição do grupo.  
◆ É o tipo de grupo. Se deixar Publico, ualquer um poderá entrar. Se deixar Moderado, poderão entrar, mas vc poderá excluir (o dono). Se deixar Somente convidados, somente quem o dono do grupo convidar é que poderá entrar.
