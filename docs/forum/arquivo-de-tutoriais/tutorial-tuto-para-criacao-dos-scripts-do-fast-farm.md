# [Tutorial]Tuto para criação dos scripts do Fast Farm

**Origem:** https://forum.tribalwars.com.br/index.php?threads/tutorial-tuto-para-cria%C3%A7%C3%A3o-dos-scripts-do-fast-farm.157611/

---

Queridos companheiros de tribal wars, e jogadores com Conta Premium.  
  
Anteriormente a este tópico (nesta seção), criei um tutorial explicando passo a passo como melhorar o rendimento do farm utilizando o script autorizado, mantendo a honestidade e utilizando os recursos do Navegador Opera.  
  
Agora, irei fazer o segundo tutorial, que completa o primeiro, que a meu ver, é de interesse de muitos jogadores que tem N aldeias e gostaria de ter scripts de farms para a maioria destas.  
  
Vamos começar...  
  
1º)Crie um grupo com as aldeias que você quer utilizar para farm e chame o grupo de maneira que achar mais conveniente. O meu grupo chama-se Farm.  
  
2º)Tenha em mente a quantidade de tropas que você vai utilizar para farmar;  
  


Código: 
    
    
    Neste exemplo eu utilizo 200 leves e 1 explorador

  
3º)Saiba configurar o script de forma correta;  
  
4º)Utilize [este](http://forum.tribalwars.com.br/showthread.php?t=117787) script:  
  


Código: 
    
    
    javascript: 
    var lanca =0; 
    var espada=0; 
    var barbaro=0;
    var arqueiro=0;
    var explorador=[COLOR="Red"]1[/COLOR]; 
    var cavalaria_leve=[COLOR="#ff0000"]200[/COLOR];
    var cavalaria_arqueira=0;
    var cavalaria_pesada=0; 
    var catapulta=0; 
    var ariete=0;
    var coords_ataque='[COLOR="Blue"]xxx|yyy[/COLOR]'; 
    
    $.getScript('http://equipetribalwars.com/scripts/saquear_aldeia_farmar.js');
    void(0);

  
5º)Abra o bloco de notas;
