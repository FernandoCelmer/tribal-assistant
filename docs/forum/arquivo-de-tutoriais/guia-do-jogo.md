Como aplicar um pacote gráfico? ​

**  
Primeiro de tudo você tem de ter um pacote gráfico, eu vou usar apenas um css porem um pacote gráfico modifica toda a parte gráfica do jogo, ou seja muda edifícios, ícones etc, o css muda toda a parte de cores etc, mas... ambos mudam algo e eu vou explicar dando o exemplo do css que é o que eu prefiro mais, porem também vou explicar como aplicar o pacote gráfico mas sem mostrar o resultado, mas este será igual ao do css.  
  
Esta é uma função de conta premium, se você não tem não vai conseguir aplicar o css.  
  
O css usado: <http://kingbushido95.kilu.de/GPs/Vista/vista_style.css>  
  
Ele vai modificar a aparência do jogo para o estilo do windows vista!  
Não vai mudar edifícios apenas cores etc  
  
Para o fazer:  
  
Vá em configurações e de seguida escolha do lado esquerdo configurações  
  
Depois faça como na imagem:  
  


![pactoj.jpg](http://img208.imageshack.us/img208/5853/pactoj.jpg)

  
  
Onde esta a verde coloque o link do css informado em cima neste mesmo post, e clique em ok que esta marcado a azul.  
  
Se você fosse colocar uma modificação de edifícios etc em vez de colocar o link do css colocava o do pacote gráfico mas na linha acima e não onde colocamos o css.  
  
Porem os pacotes gráficos podem trazer css, então colocam o pacote gráfico em cima e o css na linha de baixo.
