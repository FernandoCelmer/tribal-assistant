# Instalando, conhecendo e usando a toolbar do tribal wars

**Origem:** https://forum.tribalwars.com.br/index.php?threads/instalando-conhecendo-e-usando-a-toolbar-do-tribal-wars.120099/

---

Como a toolbar do tribal wars é uma nova novidade da innogames estamos apresentando como instalar a mesma, iremos fazer uma descrição de cada item da mesma e também ensinar como a usar.  
  
Primeiro, quais as vantagens da toolbar? primeiramente você não precisa de estar logado no tribal wars para saber quando recebe uma mensagem, quando chega um relatório e até mesmo quando esta recebendo um ataque basta que para isso esteja logado na toolbar, esteja navegando onde estiver a toolbar vai lhe dar sinal sempre que chega algo, relatório mensagem etc e ainda pode ver quando tempo resta para terminar uma construção!  
  
**Instalando a toolbar no firefox:**  
  
Primeiro deve de aceder ao site <http://toolbar.innogames.de/landing/staemme/> para fazer o download da mesma, veja a imagem abaixo:  
  


![instalar1.jpg](http://img522.imageshack.us/img522/8638/instalar1.jpg)

  
Clique em "Download" e vai aparecer o seguinte, caso use o Firefox:  
  


![instalar2.jpg](http://img688.imageshack.us/img688/6064/instalar2.jpg)

  
Clique então em "permitir" para aceder ao instalador de extensões do firefox e faça o seguinte:  
  


![instalar3.jpg](http://img339.imageshack.us/img339/8911/instalar3.jpg)

  
Clique em "instalar agora" e o seu navegador vai pedir para reiniciar o mesmo para que a instalação seja feita com sucesso, faça o reiniciar.   
  


![instalar4.jpg](http://img413.imageshack.us/img413/3281/instalar4.jpg)

  
Após efectuar a instalação já vai ter a toolbar no seu navegador, mais a frente iremos ver como fazer login, lembrando este é o meio de instalação do firefox pois no internet explorer é diferente, abaixo pode ver como instalar no internet explorer!
