**Tut. N1  
  
Para deff+cl  
  
1º Fazer lanças para farmar começem a farmar com 8 lanças e se tiver paladino utilizem ele tambem, façam ate as 115 lanças mas sempre armazenando o ferro no mercado, devem acabar com sensivelmente 4k de ferro no mercado.  
  
2º Para terem as 115 lanças devem ter a Aldeias assim:  
-Ep nivel 3  
-Quartel nivel 1  
-Mercado nivel 4  
-Armazem nivel 6  
-Muralha nivel 1  
-Fazenda nivel 3  
  
3º Upar para Leves logo devem fazer as seguintes etapas:  
Ep para nivel 10  
Ferreiro para nivel 5  
Quartel para nivel 5  
Fazenda para nivel 5  
Estabulo para nivel 3  
  
4º Pesquisar leves  
  
5º Farmar que nem louco o 12x12 com 3 leves para cada aldeia  
  
6º Irem retirando as ofertas de ferro para fazerem leves  
  
7º Enquanto deff+cl as suas prioridades serão as seguintes:  
-Lanças+Espadas  
-Exploradores(100 chegam)  
-Cls para farmarem  
  
8º Uparem recursos para 16 e quartel para 20 sempre a produzir tropas  
  
9º Finalizarem com Recursos a 24 Quartel a 25 ,estabulo a 20 e com a fazenda a 30  
  
10º Avançarem para o Nt  
  
11º COnquista, nesta devem ser prodentes tentem conquistar uma aldeia de ataque para terem minimas perdas.
